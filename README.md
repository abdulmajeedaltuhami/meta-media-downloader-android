# منزّل الوسائط (Meta Media Downloader)

تطبيق ويب حديث مبني بتقنية **React + TypeScript + Vite** لتنزيل الوسائط وفيديوهات المنصات وحفظ حالات WhatsApp، بنسخة معاد كتابتها بالكامل من تطبيق Android الأصلي، مع الحفاظ على المنطق البرمجي، والتصميم الداكن العربي الأصلي (RTL).

## المميزات والوظائف

- **فحص الروابط الذكي (Link Inspector):** دعم التحقق من روابط YouTube وFacebook وInstagram وThreads وTikTok والروابط المباشرة مع استخراج العنوان والناشر.
- **تحديد الجودة والصوت:** اختيار دقة الفيديو (أفضل جودة، 1080، 720، 480، 360) أو استخراج الصوت فقط بصيغة MP3.
- **خيارات التنزيل:** دعم تفعيل الترجمة الأصلية (عربي/إنجليزي) وخيار تنزيل القوائم الكاملة.
- **منع التكرار التلقائي (Duplicate Detection):** نظام تحقق ذكي يمنع إعادة تنزيل نفس الرابط بنفس الجودة والإعدادات لتوفير الاستهلاك.
- **حالات WhatsApp المحلية:** استعراض الحالات وحفظها مباشرة، مع إمكانية رفع واختيار ملفات الحالات من جهاز المستخدم.
- **حفظ مباشر:** حفظ الملفات مباشرة في مجلد التنزيلات على جهاز المستخدم بدون الحاجة إلى بوتات Telegram أو خوادم وسيطة خارجية.
- **سجل التنبيهات والتنزيل:** شاشة تنبيهات فورية تعرض حالة التنزيل والملفات المكتملة وتاريخ العمليات.

## التشغيل والتطوير المحلي

يتطلب تشغيل التطبيق بيئة Node.js (الإصدار 18 أو أحدث):

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء النسخة الإنتاجية
npm run build
```

يعمل خادم التطوير على المنفذ `3000` على العنوان `http://localhost:3000`.
