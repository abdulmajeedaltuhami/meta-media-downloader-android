# SEO and discoverability plan

## Repository metadata

Use a clear description containing the main search terms:

> Free non-commercial Android media downloader with Arabic RTL UI, yt-dlp and FFmpeg. Saves public YouTube, Facebook, Instagram, Threads and TikTok media directly to Download, with WhatsApp status support.

Suggested topics: `android`, `android-app`, `yt-dlp`, `ffmpeg`, `media-downloader`, `arabic`, `rtl`, `youtube-downloader`, `instagram-downloader`, `tiktok-downloader`, `whatsapp-status`, `non-commercial`.

## Content strategy

Keep the README bilingual. Put the exact terms users search for in headings, screenshots, setup steps, supported platforms, limitations, and troubleshooting. Add real screenshots and a short installation video after testing on a device. Link the repository from a personal website, GitHub profile, and relevant noncommercial technical posts; do not use spammy backlink networks.

## GitHub quality signals

Maintain a useful README, releases with checksums, a changelog, issue templates, a security policy, and a working build workflow. Respond to issues, use descriptive release notes, and keep the project active with meaningful updates rather than keyword-only commits.

## Important limitation

SEO cannot guarantee a ranking. The strongest signals are useful documentation, genuine users, working releases, relevant external references, and an accurate project description. Do not claim support for platforms or features that are not tested.
